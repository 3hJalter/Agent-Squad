🔐 Quyền của từng agent

  

    
Mặc định agent chỉ được sửa file trong project và chạy các lệnh an toàn (xem file, git cục bộ, lệnh kiểm tra). Ở đây bạn xem quyền đã cấp thêm, thu hồi từng quyền, hoặc cho phép trước theo nhóm để agent đỡ phải hỏi. Quyền có hiệu lực từ lượt làm việc tiếp theo.

    

  



  
🧠 Bộ nhớ

  

    
Bộ nhớ chung của project

      
Các quyết định, quy ước và sở thích của bạn. Mọi agent đọc phần này khi bắt đầu một cuộc trò chuyện mới, và tự ghi thêm một dòng khi bạn chốt điều gì. Bạn sửa hoặc xoá tuỳ ý; nên giữ dưới 60 dòng.

      
      

    

    
♻️ Tự làm mới cuộc trò chuyện

      
      
Cuộc trò chuyện càng dài thì mỗi bước càng tốn token, vì agent phải đọc lại tất cả. Khi vượt ngưỡng và có việc mới, agent ghi lại ghi chú của mình rồi bắt đầu cuộc trò chuyện mới, đọc lại ghi chú và bộ nhớ chung. Hiện chỉ đo được với agent Claude.

    

    
Ghi chú riêng của từng agent

      
Việc đang làm dở và những gì agent cần nhớ khi sang cuộc trò chuyện mới. Agent tự ghi khi đổi tài khoản, đổi model, khi tự làm mới, hoặc khi bạn bấm "Cập nhật ngay".

⚡ Tiết kiệm token (thử nghiệm)

      
      
context-mode (mksglu/context-mode) giữ dữ liệu lớn như log dài hay nhiều file ngoài ngữ cảnh, chỉ đưa cho agent kết quả cần dùng. Cần Node.js 22.5 trở lên trong WSL và có mạng ở lần chạy đầu (tải bằng npx). Chỉ áp dụng cho agent Claude, từ lượt nhắn tiếp theo, không cần Start lại. So sánh ở bảng 📊 Token: dòng có ⚡ là lượt chạy có context-mode, nhìn cột "TB/lượt". Rủi ro: nó cho agent chạy code trong ô riêng, nên danh sách lệnh an toàn và nút "Cho phép" không kiểm soát được phần này.

👤 Tài khoản

  

    
Mỗi hồ sơ là một tài khoản Claude hoặc Codex (ChatGPT) đăng nhập riêng. Agent không chọn hồ sơ thì dùng tài khoản đang đăng nhập sẵn trong WSL. Chọn hồ sơ cho từng agent ở tab 🤖 Đội agent, bấm "✏️ Sửa". Các agent dùng tài khoản khác nhau chạy song song được.

    

    
➕ Tạo hồ sơ

      

        
        
        
        
      

      Tạo xong, mỗi hồ sơ cần đăng nhập một lần: dashboard hiện sẵn một dòng để dán vào Ubuntu (WSL). Hồ sơ mới là thư mục cấu hình trống nên chưa có plugin hay MCP riêng của tài khoản chính. Chỉ nên dùng tài khoản của chính bạn hoặc của đội bạn.
