Đặt tên để phân biệt các worker (ví dụ frontend, backend, test); nhiều worker dùng cùng agent và model vẫn được, để trống thì tự đặt tên. "mặc định" = để agent tự chọn. Cấu hình lưu riêng cho từng project và chỉ áp dụng khi Start: nếu phiên đang chạy thì Stop rồi Start lại.
